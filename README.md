# Przemek Marzec

Software & technical architect. Building **Engrava** — an open-source memory database for AI agents — at my independent AI studio, **Sovantica**.

## What I'm building

**[Engrava](https://engrava.ai)** — an open-source memory database for AI agents: a typed knowledge graph with hybrid (vector + keyword) search, a tamper-evident audit trail, and deterministic (no-LLM) background consolidation, all in a single SQLite file. My focus is agent memory that's auditable, reproducible, and precise about what it does.
