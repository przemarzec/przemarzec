# Przemek Marzec

Software & technical architect. Building **Engrava**, the memory database for AI agents, at my independent AI studio, **Sovantica**.

## What I'm building

**[Engrava](https://engrava.ai)** is an open-source, in-process Python library over one SQLite file: a queryable memory graph with bi-temporal valid-time predicates, hybrid (vector + keyword) search, background consolidation from six fixed signals, and a SHA-256-linked journal of thought and edge changes. There is no generative-model call in the core write path. My focus is agent memory that is reproducible and precise about what it does.
